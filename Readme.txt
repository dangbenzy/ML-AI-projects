CS50 AI Projects – My Learning Portfolio

This repository contains a collection of learning projects I completed as part of Harvard's CS50's Introduction to Artificial Intelligence with Python. Each project reflects a hands-on application of key AI concepts including search algorithms, knowledge representation, optimization, and machine learning.

> 🔍 Projects include:
1. Heredity – Modeling genetic inheritance using probability.
2. Tic Tac Toe – Building an unbeatable AI using the Minimax algorithm.
3. Minesweeper – Creating a logical agent to solve the classic puzzle.
4. Degrees – Finding shortest paths between actors using graph search.
5. Knights – Solving a constraint satisfaction problem on a chessboard.
6. PageRank – Simulating Google’s PageRank algorithm for web ranking.
7. Crossword – Generating crossword puzzles using backtracking and constraints.
8. Nim – Training a reinforcement learning agent to play Nim.
9. Shopping – Applying machine learning to predict customer behavior.
10. Parser – Building a context-free grammar parser for sentence structure.
11. Traffic – Optimizing traffic light control using Q-learning.
12. Attention – Implementing attention mechanisms for natural language tasks.

Each project includes comments and structure that reflect my learning process
